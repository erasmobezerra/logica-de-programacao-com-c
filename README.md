- Entrada e saída de dados

- Operadores matemáticos
- Estruturas de decisão
- Estruturas de repetição
- Controle de fluxo
- Vetores e MAtrizes
- Structs
- Funções
- Modularização
- Resolução de exercícios de lógica

## Observação

Cada pasta contém exemplos simples para acompanhar o aprendizado e servir como referência futura.
