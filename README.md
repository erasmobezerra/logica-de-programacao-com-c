# Projeto de Aprendizado em C

Este repositório reúne meus exercícios e exemplos práticos enquanto estou aprendendo a linguagem C.

## Objetivo

Registrar o meu progresso em:

- Sintaxe básica da linguagem C
- Entrada e saída de dados
- Variáveis e atribuição
- Operadores matemáticos
- Estruturas de decisão
- Estruturas de repetição
- Controle de fluxo

## Estrutura

- `01_OlaMundo/` - primeiro programa em C
- `02_SaidaDeDados/` - exemplos com `printf`
- `03_EntradaDeDados/` - exemplos com `scanf`
- `04_variaviesEAtribuicao/` - uso de variáveis
- `05_operadoresMatematicos/` - operadores aritméticos
- `06_estruturasDeDecisao/` - `if`, `else` e `switch`
- `07_estruturasDeRepeticao/` - `for`, `while` e `do-while`
- `08_controleDeFluxo/` - uso de `break` e `continue`

## Observação

Cada pasta contém exemplos simples para acompanhar o aprendizado e servir como referência futura.
